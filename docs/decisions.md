# Решения

## 2026-11-11 — Базовая архитектура
- **Доставка перевода в игру: pak-мод в `Client/Content/Paks/~mods/`.** Альтернатива
  (OCR-оверлей) отклонена: криво и медленно. Принят риск со стороны античита и ToS.
- **Источник правды для перевода: репозиторий на GitHub**, релизы собирает CI.
  Лаунчер ничего не собирает, а только качает готовый `.pak` по `manifest.json`.
- **Лаунчер: Tauri 2.** Маленький `.exe`, веб-UI. Electron отклонён из-за размера,
  WPF — из-за трудоёмкого UI.
- **Аудитория: публичный релиз.** Отсюда обязательная проверка SHA-256, белый
  список имён файлов и удаление только своих файлов.
- **Фронтенд без фреймворка** (Vite + TypeScript): у лаунчера один экран,
  React там не нужен.
- **Сборка релиза: GitHub Actions + repak** (pak V11, UE 4.26). По тегу `v*` CI
  пакует `translation/pak/`, генерит `manifest.json` (`tools/make_manifest.py`)
  и публикует релиз. Лаунчер ходит только на `releases/latest/download/manifest.json`.
- **Безопасность загрузки:** лаунчер принимает URL только с `github.com` и
  `*.githubusercontent.com` по https, имена `*.pak` без путей, размер до 2 ГиБ,
  обязательная проверка SHA-256 до замены файлов.
