# Перевод

## Как устроено
- `pak/` — дерево файлов, которое целиком упаковывается в `wuwarus_ru_P.pak`.
  Пути внутри повторяют пути контента игры (`Client/Content/...`), файлы в нём
  подменяют оригинальные при загрузке мода из `~mods`.
- CI (`.github/workflows/release.yml`) по тегу `v*` пакует `pak/` через
  [repak](https://github.com/trumank/repak), считает SHA-256, пишет
  `manifest.json` и публикует GitHub Release. Лаунчер берёт оттуда последний релиз.

## Выпустить версию
```bash
git tag v2026.11.11-1
git push origin v2026.11.11-1
```
Версия перевода берётся из тега без `v`. Версию игры, под которую собран
перевод, и заметки к релизу задаёт `release.json`.

## Открытый вопрос
Какие именно файлы игры держат текст и в каком они формате, нужно выяснить
распаковкой текущей версии клиента. От этого зависит, что лежит в `pak/`.
