# wuwarus — русификатор Wuthering Waves с лаунчером

## Проблема
У Wuthering Waves нет официального русского языка. Нужен способ одной кнопкой поставить
актуальный русский перевод, держать его обновлённым и запускать игру.

## Пользователи
Публичный релиз: обычные игроки на Windows, без технических навыков.

## Состав системы
1. **Переводы** (`translation/`) — исходники перевода в репозитории на GitHub
   (JSON: ключ строки -> русский текст), сборочный скрипт и CI.
2. **CI** (`.github/workflows/`) — собирает из исходников `.pak`-мод и публикует
   GitHub Release с `manifest.json` и `.pak`.
3. **Лаунчер** (`launcher/`) — Tauri 2 (Rust + веб-UI). Находит игру, качает
   перевод из последнего релиза, проверяет SHA-256, кладёт `.pak` в
   `Client/Content/Paks/~mods/`, снимает перевод, запускает игру.

## Контракт релиза перевода
`https://github.com/<owner>/<repo>/releases/latest/download/manifest.json`:

```json
{
  "schema": 1,
  "version": "2026.11.11-1",
  "game_version": "2.8",
  "published_at": "2026-11-11T12:00:00Z",
  "notes": "Что нового",
  "files": [
    { "name": "wuwarus_ru_P.pak", "url": "https://...", "size": 123, "sha256": "..." }
  ]
}
```

Лаунчер ставит файлы только из `files`, только с проверенным хэшем и только с
именем без путей (`[A-Za-z0-9._-]+\.pak`).

## Поведение лаунчера
- Путь к игре: автопоиск (типовые папки на всех дисках) или выбор вручную.
  Признак игры: `Client/Binaries/Win64/Client-Win64-Shipping.exe`.
- Состояние (путь, установленная версия, имена файлов) — JSON в
  app-config-директории лаунчера.
- Установка атомарная: скачать во временный файл -> проверить хэш -> переименовать.
- Снятие перевода удаляет только файлы, которые ставил сам лаунчер.
- Запуск: `Wuthering Waves.exe` в корне игры (если нет — `Client-Win64-Shipping.exe`).

## Вне MVP
- Самообновление лаунчера (tauri-plugin-updater + ключ подписи).
- Сборка `.pak` из исходников: нужен разбор формата текстов игры (см. риски).

## Риски
- **Формат текстов и загрузка модов могут ломаться на каждом патче игры.**
  Перевод привязан к `game_version`; лаунчер предупреждает о несовпадении.
- **Античит / ToS.** Pak-моды формально нарушают ToS. Лаунчер явно об этом
  предупреждает при первой установке.
- Неподписанный `.exe` будет пугать SmartScreen — нужна подпись кода для релиза.
